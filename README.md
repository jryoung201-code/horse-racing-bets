# Horse Racing

Simple horse race. Horses rest at the gate. Hit **Start race**. Each horse rolls **0.01–1.00** — higher runs faster.

Play: https://jryoung201-code.github.io/horse-racing-bets/

Or locally:

```bash
git clone https://github.com/jryoung201-code/horse-racing-bets.git
cd horse-racing-bets
npm install
npm start
```

Open http://localhost:3000
